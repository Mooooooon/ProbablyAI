# 深空AI：可能是DeepSeek

为《深空当铺：可能是偷的》添加像素风鲸鱼娘女仆助手“小鲸”。[English guide](README.en.md)。

在 Mods 菜单启用并审核联网能力后重启。进入当铺，点击左侧立绘打开聊天；F6 显隐立绘，F7 打开助手设置。需要自备支持 OpenAI 通用格式的服务与 API Key，操作游戏还需要模型支持工具调用。默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`；可获取模型列表或手动填写。

界面、默认提示词和工具说明自动跟随游戏内的中英文语言设置，其他语言使用英文。切换语言后重新打开 Mod 面板即可。自定义提示词和你输入的文字完整保留。默认小鲸称呼你为“主人”，英文为“Master”，语气活泼可爱，除非明确要求，否则不用颜文字或 emoji。

F7 可查看并修改完整提示词、恢复默认，点击保存配置后用于下次消息；也可在保存前发送测试消息预览。保存新提示词后，下次发送会清理旧对话上下文；聊天历史只在当前载入的内存中保留。

试试：“把物品栏里的食物放到柜台上”“当前客人想买什么，还剩多少预算？”“找出适合这个客人的物品，先告诉我，不要移动”“把档案架里导师笔记中的一份笔记拿到柜台”。

支持查询和移动真实物品、嵌套文件夹与背包、储藏分页及机器分区；支持上柜台、入库、归档、投放垃圾桶和机器投料。可读取当前客人的意图、剩余购买预算、购买偏好、拒收规则与特殊委托需求，检查具体物品是否符合普通购买偏好和当前预算。所有移动遵循原生规则，部分成功会如实返回。

目前不提供自动成交、选择对话、解锁、生成物品或启动机器的操作。原生回调与自动加工仍按游戏逻辑运行。停止只取消后续动作，已完成的移动保留。

只有获取模型、发送测试、聊天或执行指令才会联网；工具查询到的游戏信息会发送给你配置的服务商。勾选记住 API Key 时，密钥以明文保存在本机独立的 Mod 数据文件 `ModData/probably_ai/connection.local.json`；取消勾选后保存可仅本次运行使用。不要分享个人配置文件。服务商费用由你自行承担，Mod 不提供共享密钥或额度。

上传包只有 Mod DLL、manifest、中英文指南、立绘和封面，不包含个人连接配置、API Key、存档、账号数据、游戏 DLL、调试符号或研究缓存。仅声明联网能力。

Beta v0.6.0，针对应用版本 0.46D / VERSION 100-Rev3 的原生 Mod API 编译。自动检查使用模拟游戏状态和 HTTP，真实游戏行为与服务商兼容性由玩家实测。独立同人 Mod，非 DeepSeek 官方产品；角色与封面为基于参考形象的 AI 生成素材。
