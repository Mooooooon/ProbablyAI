# 深空AI：可能是DeepSeek

为《深空当铺：可能是偷的》添加当铺女仆助手“小鲸”。[English guide](README.en.md)。

你可以直接用自然语言（人话）和小鲸交谈，让她帮你跑腿整理柜台、分类整理仓库物资，或者帮你打听客人的预算和需求！

## 💡 开发者的话

## ✨ 目前已有功能

- **立绘互动与自然语言聊天**：进入当铺后，小鲸常驻在左侧界面，待机时会以脚底为基准轻轻改变身高，像在呼吸，脚部不会浮动。点击人物即可开启聊天窗口自由交谈；按 **F6** 可快速显示或隐藏立绘，呼吸的开关、幅度和周期可在 Mods 设置中调整。
- **帮理当铺与整理物品**：支持自然语言吩咐小鲸搬运与整理物资。例如：“把背包里的食物全部摆到柜台上”、“把废金属放进熔炉原料区”、“把档案架里导师笔记中的某份笔记拿到柜台”。支持背包、多层嵌套文件夹、多页储藏箱和机器分区的物品识别与整理。
- **打探客人意图与委托**：可询问当前到店客人的买卖意向、实时剩余预算、购买偏好、拒收条件及特殊委托（易货/采购/枪械委托）需求，也能先核对物品栏里是否有符合客人预算和偏好的货品。
- **机械手、香烟与食品券鉴定**：解锁目视检查后，可让小鲸读取机械手的材质、接口、磨损、套装与原生基准价，香烟的封条、标志、文字和包装，以及食品券的防伪标、芯片、文字与票面面值，并说明可见异常。以上均为只读查询，不会提交估价、质问客人或兑换食品券。
- **通缉犯与改造体提醒**：客人符合通缉令特征或是改造体时，小鲸会在回复末尾小声提醒；不会当着客人说破，也不会自动举报、攻击或改变交易。
- **阅读笔记、书籍与指南**：可读取导师笔记、情报单、书籍页，以及香烟、食品券、注射器、机械手等指南和通缉令上的可见文字；只读，不打开窗口、不翻页、不改变物品。
- **聊天快捷发言**：聊天框提供“按照客户需求挑选商品”和“帮我鉴定对方带来的东西”两个快捷按钮。前者按当前客人的需求与预算挑选货品并直接摆上柜台；后者逐件检查窗口里客人带来的物品。
- **思考级别**：F7 设置中可选择跟随模型默认、关闭思考、低、高、最高；按服务支持发送 thinking 与 reasoning_effort。
- **含加成的价格与预算检查**：上柜台前预估多种多样、实时价格事件、零售加价及已知客人效果，按游戏乘区计算并返回明细；柜台顶层物品读取原生实时报价。上柜台、检查或谈价后会重新查询，避免把基础价当成交价或重复叠加加成。
- **实况刷新与历史区分**：每条聊天消息会重新读取当前客人和柜台内容、数量、所有权，并随消息发送给所配置的模型。历史查询不作为当前状态，防止把上一单已售出的物品误认为仍待售；默认回复直接报告金额和预算结论，需要时再解释价格来源。
- **开放的模型接入与自定义人设（F7）**：按 **F7** 打开设置面板，支持配置任何兼容 OpenAI 接口规范的服务地址（默认推荐 DeepSeek 官方 API，也可使用其他兼容服务或本地模型）。默认预设了活泼可爱的女仆助手人设，您也可以在面板中自由编辑自定义提示词并实时测试预览。
- **中英文自动跟随**：界面、默认提示词和工具说明自动跟随游戏内的中英文语言设置切换。
- **聊天窗口位置记忆**：拖动后的窗口位置会在关闭再打开及重启游戏后恢复。位置独立保存在本机 `chat-window.local.json`，不包含对话或密钥，不随 Mod 上传。

## 🛠️ 快速上手与使用注意

1. 在游戏 Mods 菜单启用模组并确认允许联网权限后，重启游戏。
2. 进入当铺后按 **F7** 打开设置，填入 API 地址与 API Key（默认推荐 DeepSeek 官方 API：`https://api.deepseek.com`，模型 `deepseek-flash`）。
3. **自备 API Key**：本 Mod 为本地直连模型服务商，需玩家自备 API Key，不内置额度。API Key 仅保存在本机游戏配置中，请妥善保管。
4. **游戏规则**：小鲸的所有搬运操作均严格遵循原生游戏规则，不会凭空刷取物品，也不会擅自帮你点击交易完成或做经济结算。
